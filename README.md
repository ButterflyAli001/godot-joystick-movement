# Godot 4 Joystick Movement System

Sistem pergerakan berbasis joystick untuk Godot 4.6 yang dirancang untuk game mobile dan kontrol layar sentuh. Menyediakan pergerakan yang halus, responsif, serta mudah diintegrasikan ke dalam project.

## ✨ Fitur

* Kontrol joystick untuk pergerakan karakter
* Input halus dan responsif
* Mudah diintegrasikan ke project lain
* Kode clean dan mudah dipahami

## 📦 Instalasi

1. Clone repository ini:

   ```
   git clone https://github.com/username/godot-4-joystick-movement-system.git
   ```
2. Copy gdscript dan scene
3. Assign scene joystick dan player pada world yang kau buat
4. Pastikan semua script terattach dengan benar dan selesai

## 🎮 Cara Penggunaan

* Gunakan joystick di layar untuk menggerakkan karakter
* Arah joystick menentukan arah gerakan
* Jarak dari pusat joystick menentukan kecepatan
* Ubah anchor joystick sesuai yang diinginkan

## 📁 Struktur Project

* `scenes/` → berisi scene utama
* `scripts/` → script untuk sistem joystick dan movement

## 🛠️ Kustomisasi

Kamu bisa dengan mudah menyesuaikan:

* Sensitivitas joystick
* Kecepatan karakter
* Ukuran dan posisi joystick

## 📱 Cocok untuk

* Game mobile (Android/iOS)
